# Breakout

SDL3 / C11 で作った、マウス操作の Windows 向けブロック崩しです。

## Windows でビルド

次のツールをインストールしてください。

- Visual Studio 2022 または 2026（「C++ によるデスクトップ開発」。無料の Community または Build Tools でも可）
- CMake 3.24 以上（PATH、標準のインストール先、Visual Studio 付属版を自動検出）
- Git for Windows（PATH へ追加）

リポジトリ内の `build_windows.bat` を実行します。初回はインターネットから SDL 3.2.10 を取得するため、時間がかかります。SDL3 の手動インストールは不要です。

```bat
build_windows.bat
play_windows.bat
```

ビルド結果は `build\bin\breakout.exe` です。SDL3 は静的リンクされるため、SDL3.dll のコピーは不要です。バッチは自身のフォルダへ移動するので、別の作業フォルダからでも実行できます。ビルド終了時はキー入力を待つため、ダブルクリックしても結果を確認できます。起動用バッチも、実行ファイルがない場合やゲームが異常終了した場合はエラーを表示してキー入力を待ちます。

## 操作と進行

- タイトル画面で左クリックするとゲーム開始。
- マウスの左右移動でパドルを操作。左クリックでボールを発射。
- ボールを落とすと残機が1減り、左クリックで再発射。
- 3回落とすとゲームオーバー。左クリックでタイトルに戻る。
- 全ブロックを消すとステージクリア。左クリックで次のステージへ進み、さらにクリックで発射。
- 残機とスコアは次のステージに引き継ぐ。配置は3種類で繰り返し、ボール速度は段階的に上昇（上限あり）。
- Esc またはウィンドウを閉じると終了。フォーカスが外れるとゲーム進行を一時停止。

画面は 960×720 を基準に、ウィンドウサイズに合わせて縦横比を保って表示します。追加の画像・フォント・音声ファイルは使いません。画面内テキストは SDL3 内蔵フォントによる英語表示です。

## 構成

- `src/main.c`: 画面遷移、ゲーム処理、描画
- `CMakeLists.txt`: SDL3 の取得とビルド設定
- `build_windows.bat`: インストール済み Visual Studio の x64 Release ビルド
- `play_windows.bat`: ビルド済みゲームの起動

Linux でも CMake と C コンパイラ、および SDL3 が必要とする開発ライブラリがあれば `cmake -S . -B build`、`cmake --build build --parallel` でビルドできます。

CMake が見つからない場合は、Visual Studio Installer の「変更」から「C++ によるデスクトップ開発」の「Windows 用 C++ CMake ツール」を追加するか、CMake を PATH に追加してからバッチを開き直してください。独立版の標準パスは `C:\Program Files\CMake\bin` です。

ビルド時は CMake がインストール済みの Visual Studio を選びます。毎回 `--fresh` で前回の CMake 設定をリセットするため、以前のジェネレーターやツールセット指定は引き継ぎません（取得済み SDL3 ソースやビルド成果物は削除しません）。

## 落下位置の予測表示

下降中、ボール中心が Y=290 を越えると、5フレーム刻みで30フレーム先までの予測球を表示します（60fps 換算、最大0.5秒先）。30フレーム先の不透明度は0%、25フレーム先は5%、以降5フレーム戻るごとに5%増加します。現在のボール本体は通常どおり不透明です。

予測全体の不透明度に、Y=290 で0倍、Y=425 で1倍となる係数を掛け、その間は直線的にフェードインします。基準となる黄色・赤色のラインは描画しません。上昇中と発射待ち、ゲーム終了時は予測を表示しません。

予測では現在のパドル位置を固定してゲーム処理のコピーを進め、壁の反射も反映します。パドルでの反射または落下までを表示し、それ以降は表示しません。予測が実際の残機・スコア・ブロックへ影響することはありません。
