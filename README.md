# BreakBout

SDL3 / C11 で作った、マウス操作の Windows 向けブロック崩しです。

## Windows でビルド

次のツールをインストールしてください。

- Visual Studio 2022 または 2026（「C++ によるデスクトップ開発」。無料の Community または Build Tools でも可）
- CMake 3.24 以上（PATH、標準のインストール先、Visual Studio 付属版を自動検出）
- Git for Windows（PATH へ追加）

リポジトリ内の `build_windows.bat` を実行します。初回はインターネットから SDL 3.2.10 を取得するため、時間がかかります。SDL3 の手動インストールは不要です。

```bat
build_windows.bat
play_windows.bat
```

ビルド結果は `build\bin\breakout.exe` です。SDL3 は静的リンクされるため、SDL3.dll のコピーは不要です。バッチは自身のフォルダへ移動するので、別の作業フォルダからでも実行できます。ビルド終了時はキー入力を待つため、ダブルクリックしても結果を確認できます。起動用バッチも、実行ファイルがない場合やゲームが異常終了した場合はエラーを表示してキー入力を待ちます。

## 操作と進行

- タイトル画面で左クリックするとゲーム開始。
- マウスの左右移動でパドルを操作。左ボタンを押してチャージし、離すと発射。
- ボールを落とすと残機が1減り、パドル上から再発射。パドルで受けたボールもくっつき、再チャージできます。
- 3回落とすとゲームオーバー。左クリックでタイトルに戻る。
- 全ブロックを消すとステージクリア。左クリックで次のステージへ進み、左ボタンを押して離すと発射。
- 残機とスコアは次のステージに引き継ぐ。配置は3種類で繰り返し、ボール速度は段階的に上昇（上限あり）。
- Esc またはウィンドウを閉じると終了。フォーカスが外れるとゲーム進行を一時停止。

画面は 960×720 を基準に、ウィンドウサイズに合わせて縦横比を保って表示します。追加の画像・フォント・音声ファイルは使いません。画面内テキストは SDL3 内蔵フォントによる英語表示です。

## 構成

- `src/main.c`: 画面遷移、ゲーム処理、描画
- `CMakeLists.txt`: SDL3 の取得とビルド設定
- `build_windows.bat`: インストール済み Visual Studio の x64 Release ビルド
- `play_windows.bat`: ビルド済みゲームの起動

Linux でも CMake と C コンパイラ、および SDL3 が必要とする開発ライブラリがあれば `cmake -S . -B build`、`cmake --build build --parallel` でビルドできます。

CMake が見つからない場合は、Visual Studio Installer の「変更」から「C++ によるデスクトップ開発」の「Windows 用 C++ CMake ツール」を追加するか、CMake を PATH に追加してからバッチを開き直してください。独立版の標準パスは `C:\Program Files\CMake\bin` です。

ビルド時は CMake がインストール済みの Visual Studio を選びます。毎回 `--fresh` で前回の CMake 設定をリセットするため、以前のジェネレーターやツールセット指定は引き継ぎません（取得済み SDL3 ソースやビルド成果物は削除しません）。

## 落下位置の予測表示

下降中、ボール中心が黄色相当の Y=290 を通過した瞬間の位置と速度を記録し、パドルに接触するボール中心の高さ（Y=642）までの距離を10等分します。10%、20%、…、100%の地点に予測球を配置し、ボールが通過した地点の予測球は消します。フレーム数や描画頻度、ボールの速さによって分割間隔は変わりません。

予測球は遠いほど薄く表示します（90%=5%、80%=10%、…、10%=45%）。パドルの接触高さにある最後の予測球（100%地点）も、不透明度5%で表示します。現在のボール本体は通常どおり不透明です。

予測全体の不透明度に、現在のボールが Y=290 で0倍、Y=425 で1倍となる係数を掛け、その間は直線的にフェードインします。黄色・赤色のラインは描画しません。上昇中と発射待ち、ゲーム終了時、パドルの接触高さを過ぎた後は予測を表示しません。

予測には左右の壁での反射を反映します。パドル移動によって予測地点は変化せず、実際の残機・スコア・ブロックにも影響しません。

## キャッチとチャージショット

ボールがパドル上面に当たると、その接触位置にくっつき、パドルと一緒に移動します。左ボタンを押している間にチャージし、離すと上向きに発射します。ステージ開始時・ミス後も同じ操作です。飛行中に押し始めた場合も、キャッチしてからチャージが進みます。

チャージは1秒で最大になり、パドルが赤く変化して強く震えます。振動は見た目だけで、当たり判定は動きません。チャージ量は画面に百分率で表示します。

発射速度はチャージなしで通常の1倍、最大で2.5倍です。貫通回数はチャージ量に比例して0〜5回で、最大チャージなら5個のブロックを反射せず破壊し、その次のブロックでは通常どおり反射します。速度は次のキャッチまたはミスまで維持されます。

チャージして発射したボールでブロックを壊すと、色付きの破片が飛び散って落下しながら消えます。破片は描画専用で、他のブロック・パドル・ボールには衝突しません。フォーカスが外れた場合はチャージを解除し、勝手に発射しません。

## パドルの残像とミス演出

通常プレイ中は、直近0.2秒の位置・角度の履歴から残像を表示します。遅い移動では0.2秒前の位置に1枚、速くなるほど枚数が増え、平均移動速度1200px/秒以上では現在から0.2秒前までの間に6枚を等間隔で表示します（約0.033秒刻み）。位置と速度は960×720の論理座標が基準です。

下降するボールの衝突は本体のパドルを先に判定し、本体に当たれば吸着します。本体に当たらず残像に当たった場合は吸着せず反射し、球速と残りの貫通回数を維持します。

ボールを落とすと本体と残像が消え、パドルが3つに分かれて回転しながら飛び散ります。約0.85秒の演出後、残機があればパドルとボールが復帰し、なければゲームオーバーになります。パドルの破片に当たり判定はありません。

## 移動による傾き・発射方向の調整

通常プレイ中に左右へ移動すると、移動方向にパドルが徐々に傾きます。移動量1pxあたり0.15度ずつ変化するため、速く移動するほど傾く速度も上がり、角度は左右40度で止まります。移動を止めると毎秒90度で水平へ戻り、反対へ動かすと逆向きに調整できます。右ボタンの操作は不要です。

吸着した瞬間の当たり位置から、通常反射と同じ基準角を保存します。中央なら真上、左寄りなら左上、右寄りなら右上が基準です。発射方向は「保存した基準角＋現在のパドルの傾き」です。吸着中の点線と矢印も、この合成した方向を表示します。移動で角度を調整して左ボタンを離すと、その瞬間の方向へ発射します。ガイドと発射方向はチャージ量によらず一致します。ステージ開始時とミス後は、基準角が0度（真上）になります。

傾きに合わせて吸着位置・本体の当たり判定も回転し、残像は過去の位置と角度を保持します。本体の判定を残像より優先するルールは同じです。
