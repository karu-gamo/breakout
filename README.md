# BreakBout

SDL3 / C11 で作った、マウス操作の Windows 向けブロック崩しです。

## Windows でビルド

次のツールをインストールしてください。

- Visual Studio 2022 または 2026（「C++ によるデスクトップ開発」。無料の Community または Build Tools でも可）
- CMake 3.24 以上（PATH、標準のインストール先、Visual Studio 付属版を自動検出）
- Git for Windows（PATH へ追加）

リポジトリ内の `build_windows.bat` を実行します。初回はインターネットから SDL 3.2.10 を取得するため、時間がかかります。SDL3 の手動インストールは不要です。

```bat
build_windows.bat
play_windows.bat
```

ビルド結果は `build\bin\breakout.exe` です。SDL3 は静的リンクされるため、SDL3.dll のコピーは不要です。バッチは自身のフォルダへ移動するので、別の作業フォルダからでも実行できます。ビルド終了時はキー入力を待つため、ダブルクリックしても結果を確認できます。起動用バッチも、実行ファイルがない場合やゲームが異常終了した場合はエラーを表示してキー入力を待ちます。

## 操作と進行

- タイトル画面で左クリックするとゲーム開始。
- マウスの左右移動でパドルを操作。左ボタンを押してチャージし、離すと発射。
- ボールを落とすと残機が1減り、パドル上から再発射。パドルで受けたボールもくっつき、再チャージできます。
- 3回落とすとゲームオーバー。左クリックでタイトルに戻る。
- 全ブロックを消すとステージクリア。左クリックで次のステージへ進み、左ボタンを押して離すと発射。
- 残機とスコアは次のステージに引き継ぐ。配置は3種類で繰り返し、ボール速度は段階的に上昇（上限あり）。
- Esc またはウィンドウを閉じると終了。フォーカスが外れるとゲーム進行を一時停止。

画面は 960×720 を基準に、ウィンドウサイズに合わせて縦横比を保って表示します。ボール画像は `data/ball.png` をビルド時に実行ファイルへ組み込みます。配布時に追加の画像・フォント・音声ファイルを置く必要はありません。画面内テキストは SDL3 内蔵フォントによる英語表示です。

## 構成

- `src/main.c`: 画面遷移、ゲーム処理、描画
- `CMakeLists.txt`: SDL3 の取得とビルド設定
- `build_windows.bat`: インストール済み Visual Studio の x64 Release ビルド
- `play_windows.bat`: ビルド済みゲームの起動

Linux でも CMake と C コンパイラ、および SDL3 が必要とする開発ライブラリがあれば `cmake -S . -B build`、`cmake --build build --parallel` でビルドできます。

CMake が見つからない場合は、Visual Studio Installer の「変更」から「C++ によるデスクトップ開発」の「Windows 用 C++ CMake ツール」を追加するか、CMake を PATH に追加してからバッチを開き直してください。独立版の標準パスは `C:\Program Files\CMake\bin` です。

ビルド時は CMake がインストール済みの Visual Studio を選びます。毎回 `--fresh` で前回の CMake 設定をリセットするため、以前のジェネレーターやツールセット指定は引き継ぎません（取得済み SDL3 ソースやビルド成果物は削除しません）。

## 落下位置の予測表示

下降中、ボール中心が黄色相当の Y=290 を通過した瞬間の位置と速度を記録し、パドルに接触するボール中心の高さ（Y=634）までの距離を10等分します。10%、20%、…、100%の地点に予測球を配置し、ボールが通過した地点の予測球は消します。フレーム数や描画頻度、ボールの速さによって分割間隔は変わりません。

予測球は遠いほど薄く表示します（90%=5%、80%=10%、…、10%=45%）。パドルの接触高さにある最後の予測球（100%地点）も、不透明度5%で表示します。現在のボール本体は通常どおり不透明です。

予測全体の不透明度に、現在のボールが Y=290 で0倍、Y=425 で1倍となる係数を掛け、その間は直線的にフェードインします。黄色・赤色のラインは描画しません。上昇中と発射待ち、ゲーム終了時、パドルの接触高さを過ぎた後は予測を表示しません。

予測には左右の壁での反射を反映します。パドル移動によって予測地点は変化せず、実際の残機・スコア・ブロックにも影響しません。

## キャッチとチャージショット

ボールがパドル上面に当たると、その接触位置にくっつき、パドルと一緒に移動します。左ボタンを押している間にチャージし、離すと上向きに発射します。ステージ開始時・ミス後も同じ操作です。飛行中に押し始めた場合も、キャッチしてからチャージが進みます。

チャージは1秒で最大になり、パドルが赤く変化して強く震えます。振動は見た目だけで、当たり判定は動きません。チャージ量は画面に百分率で表示します。

発射速度はチャージなしで通常の1倍、最大で2.5倍です。貫通回数はチャージ量に比例して0〜5回で、最大チャージなら5個のブロックを反射せず破壊し、その次のブロックでは通常どおり反射します。速度は次のキャッチまたはミスまで維持されます。

チャージして発射したボールでブロックを壊すと、色付きの破片が飛び散って落下しながら消えます。破片は描画専用で、他のブロック・パドル・ボールには衝突しません。フォーカスが外れた場合はチャージを解除し、勝手に発射しません。

## パドルの残像とミス演出

通常プレイ中は、直近0.2秒の位置・長さの履歴から残像を表示します。遅い移動では0.2秒前の位置に1枚、速くなるほど枚数が増え、平均移動速度1200px/秒以上では現在から0.2秒前までの間に12枚を等間隔で表示します（約0.017秒刻み）。位置と速度は960×720の論理座標が基準です。

下降するボールの衝突は本体のパドルを先に判定し、本体に当たれば吸着します。本体に当たらず残像に当たった場合は吸着せず反射し、球速と残りの貫通回数を維持します。

ボールを落とすと本体と残像が消え、パドルが3つに分かれて回転しながら飛び散ります。約0.85秒の演出後、残機があればパドルとボールが復帰し、なければゲームオーバーになります。パドルの破片に当たり判定はありません。

## 移動速度によるパドルの伸縮

パドルは常に水平です。左右の移動速度に応じて長さが通常120pxから最大240px（2倍）まで伸びます。速度は短い時間で平滑化し、約1200px/秒で最大長になります。移動を止めると徐々に通常の長さへ戻ります。伸びた部分にも本体のキャッチ判定があり、画面端で伸びても中心位置は補正せず、画面外へはみ出します。

残像は過去の位置とその時点の長さを保持し、同じ形で当たり判定を行います。ミス時の3つの破片も、そのときのパドルの長さを反映します。縮んだときは吸着中の球がパドルの外へはみ出さないよう位置を調整します。

発射方向は、キャッチ時のパドルの長さと当たり位置から保存した通常の反射角です。中央なら真上、左寄りなら左上、右寄りなら右上になります。ガイドも同じ方向を表示し、キャッチ後の伸縮で保存した角度は変わりません。ステージ開始時とミス後は真上が基準です。

## 3球入りブロックとマルチボール

通常ブロック10個につき特殊ブロック1個となるよう、既存配置の11個ごとに1個をランダムで置き換えます（端数切り捨て）。特殊ブロックには黄色い枠と、内部で激しく動く3個の小さな球を表示します。起動時に乱数を初期化するため、配置はプレイごとに変わります。

特殊ブロックがボールに壊されると3球が飛び出します。衝突したボールの速度が大きいほど勢いよく飛び、加速度930px/秒²の重力で落下します。下向き速度の上限は3600px/秒です。放出球はほかのブロックも破壊でき、衝突速度に応じて反動を受けます。別の特殊ブロックを壊した場合も3球を放出します。

本体のパドルでキャッチすると通常球に変わり、重力の影響を受けなくなります。残像では吸着せず反射し、重力の影響を受け続けます。吸着した球はそれぞれの当たり位置から基準角を保存し、球ごとに発射ガイドを表示します。左ボタンで吸着中の全球を同時にチャージし、離すとそれぞれのガイド方向へ発射します。チャージ時間は球数によらず1秒です。

複数球がある間は、1球を落としてもほかの球で続行します。全球を落とした時点で残機が1減り、パドルの分裂演出後に1球から再開します。ステージ移行時も1球から開始します。画面上部の BALLS が現在の球数です。ブロック破片には従来どおり当たり判定がありません。

## ロジックテスト（任意）

通常のビルドではテストは無効です。有効化すると、ランダム配置・3球放出・重力・反動・複数キャッチ・チャージ・発射方向・ガイド描画・全球落下・残像・落下予測をウィンドウなしで確認できます。

```text
cmake -S . -B build -DBREAKBOUT_BUILD_TESTS=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

## やわらかいボール

プレイ中の球は半径16px・直径32pxです。通常球、放出球、落下予測の表示に同じサイズを使います。ブロック内の3球は小さなアイコンで表現します。

壁やブロックで反射する際は、約0.0325秒間その場で接触面に向かってつぶれてから速度を反転します。接触面に垂直な方向には薄く、平行な方向には広くなり、反射直後は進行方向に長く、その横方向に細い形になり、0.5秒かけて丸い形へ戻ります。ブロックの破壊・得点は最初の接触時に発生し、待機中に二重加算されません。貫通回数が残っているチャージ球は、ブロックでは停止せず通り抜けます。パドル本体への吸着と残像への反射は従来どおりです。

## ボール画像とスピン

`data/ball.png`（透過PNG）を通常球・放出球・予測球・ブロック内の小球に使用します。画像はCMakeで実行ファイルへ組み込み、32×32pxで表示します。画像を差し替えて再ビルドすると反映されます。PNGの読み込みには同梱の stb_image を使うため、追加DLLは不要です。

壁やブロックへの衝突で球がスピンします。衝突速度が大きいほど回転が速く、回転速度は約1秒でゼロまで減衰します。回転とつぶれる変形は同時に適用され、チャージ貫通でブロックを壊した場合にもスピンします。回転は表示だけに適用し、球の進路や当たり判定には影響しません。

パドルからの発射・残像での打ち返しでもスピンします。中央では回転せず、外側へ当たるほど回転が強くなり、左右で回転方向が変わります。吸着した球は、キャッチ時に保存した基準角に応じたスピンで発射します。この回転も約1秒で止まります。球の画像にはチャージや放出状態による色変更を掛けず、元のPNGの色を使います（落下予測のみ透過表示）。
